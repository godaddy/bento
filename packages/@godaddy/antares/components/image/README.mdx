## Features

- Renders a native `<img>` and accepts all of its attributes
- Inherits presentation and behavior when composed inside Antares components such as Avatar
- Ships no default styles, loading state, or fallback so it stays predictable everywhere

## Installation

```bash
npm install @godaddy/antares
```

<Examples of={Stories.Examples} />

## Accessibility

- Provide concise, meaningful `alt` text when the image conveys information.
- Use `alt=""` for decorative images or images already described by adjacent text.
- Set `width` and `height` when known to reserve space and reduce layout shift.
